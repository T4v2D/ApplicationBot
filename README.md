# ApplicationBot

Telegram-бот для приёма заявок на Python.

## Возможности
- пошаговый сбор данных пользователя
- сохранение заявок в SQLite
- FSM-сценарий
- просмотр последней заявки администратором
- подсчёт общего числа заявок
- уведомление администратора о заявке

## Стек
- Python
- aiogram 3.x
- SQLite
- asyncio

## Запуск
1. Установить зависимости
2. Создать `.env`
3. Запустить бота
